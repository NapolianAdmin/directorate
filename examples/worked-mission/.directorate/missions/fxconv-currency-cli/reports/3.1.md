LESSON CANDIDATE
Frankfurter (and likely other Cloudflare-fronted public APIs) silently 403s the stdlib default `Python-urllib/x.y` User-Agent — any urllib-based HTTP client hitting a live third-party API should set an explicit User-Agent by default, not just when a bug report forces it. Additionally: when translating `HTTPError` into a domain exception, never collapse "any non-2xx status" into one bucket — check the specific status code against what the API actually documents before deciding it means "bad input" vs. "transient/service failure."
